# SmartFlora：基于 STM32 的智能花房控制系统

基于 STM32F103C8T6 的智能花房控制系统，集成环境监测、自动控制、多级报警、安防联动与上位机通信。系统采用**非阻塞状态机**架构，实现传感器采集、OLED 交互、阈值调节、执行器联动的完整闭环，并通过 Flash 实现阈值掉电保存。

## 功能特性

| 模块 | 说明 |
|------|------|
| **环境监测** | 温湿度（DHT11）、光照（光敏电阻 + ADC）、土壤湿度（电容式 + ADC） |
| **本地显示** | OLED 实时显示 4 项数据 + 系统状态 |
| **人机交互** | 独立按键 + EC11 编码器，支持阈值调节、状态切换 |
| **数据分级** | 良好 / 一级异常 / 二级异常，三级报警机制 |
| **系统报警** | ≥3 个二级异常自动进入系统报警，支持锁定与手动解除 |
| **闭环控制** | 光照 PWM 补光、湿度联动加湿/通风、土壤联动灌溉 |
| **安防联动** | 红外人体感应 + 舵机开门 |
| **上位机通信** | 串口文本协议，支持 `GET` / `SET` / `CTRL` / `MODE` / `DOOR` / `ALARM CLEAR` |
| **掉电保存** | 阈值参数写入 Flash，带校验位 + 字节对齐 |

## 状态机设计

系统采用 **6 状态非阻塞状态机** 管理整个交互流程：

### 状态1：数据面板（主界面）
- 显示：温度、湿度、光照、土壤、PWM占空比、系统状态
- 后台：传感器采集、自动控制、报警判断
- KEY1 短按 → 进入状态2
- 二级异常 ≥3 → 自动进入状态4

### 状态2：选择指标
- 显示：Temp / Humi / Light / Soil（带光标）
- KEY1 短按 → 切换指标
- KEY1 长按 → 进入状态3
- KEY2 短按 → 返回状态1

### 状态3：调节阈值
- 显示：当前指标的最大/最小阈值（带光标）
- 编码器旋转 → 调节数值
- KEY1 短按 → 切换最大值/最小值
- KEY1 长按 → 保存到 Flash，显示 "Saved!"，返回状态1
- KEY2 短按 → 返回状态2

### 状态4：系统报警
- 显示：`!! SYSTEM ALERT !!` + 异常指标列表
- 蜂鸣器持续响，屏幕闪烁
- KEY2 长按 → 退出状态4，锁定（不再自动进入）
- 触发条件：二级异常 ≥3

### 报警锁定与解锁
- **锁定后**：即使二级异常 ≥3，也不再自动进入状态4
- **解锁条件**（三种）：
  ① 状态1 长按 KEY2
  ② 上位机 `ALARM CLEAR` 指令
  ③ 异常全部恢复（自动解锁）

### 按键功能一览

| 状态 | KEY1 短按 | KEY1 长按 | KEY2 短按 | KEY2 长按 | 编码器 |
|------|-----------|-----------|-----------|-----------|--------|
| 状态1 | 进入状态2 | - | - | 解锁报警 | - |
| 状态2 | 切换指标 | 进入状态3 | 返回状态1 | - | - |
| 状态3 | 切换最大/最小 | 保存并返回状态1 | 返回状态2 | - | 调节数值 |
| 状态4 | - | - | - | 退出+锁定 | - |

## 核心设计

- **非阻塞状态机**：按键、编码器、显示、控制全部基于时间戳，主循环无 `delay`
- **三级报警机制**：良好 / 一级异常 / 二级异常，工业级“报警确认/复位”分离设计
- **Flash 掉电保存**：校验位放首位、4 字节对齐、定点数存储
- **电源分离 + 单点共地**：逻辑电源和功率电源分离，抑制感性负载干扰
- **串口协议**：超时判断帧结束，不依赖换行符，兼容不定长指令
