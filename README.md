# SmartFlora：基于 STM32 的智能花房控制系统

基于 STM32F103C8T6 的智能花房控制系统，集成环境监测、自动控制、多级报警、安防联动与上位机通信。系统采用**非阻塞状态机**架构，实现传感器采集、OLED 交互、阈值调节、执行器联动的完整闭环，并通过 Flash 实现阈值掉电保存。

## 功能特性

| 模块 | 说明 |
|------|------|
| **环境监测** | 温湿度（DHT11）、光照（光敏电阻 + ADC）、土壤湿度（电容式 + ADC） |
| **本地显示** | OLED 实时显示 4 项数据 + 系统状态 |
| **人机交互** | 独立按键 + EC11 编码器，支持阈值调节、状态切换 |
| **数据分级** | 良好 / 一级异常 / 二级异常，三级报警机制 |
| **系统报警** | ≥3 个二级异常自动进入系统报警，支持锁定与手动解除 |
| **闭环控制** | 光照 PWM 补光、湿度联动加湿/通风、土壤联动灌溉 |
| **安防联动** | 红外人体感应 + 舵机开门 |
| **上位机通信** | 串口文本协议，支持 `GET` / `SET` / `CTRL` / `MODE` / `DOOR` / `ALARM CLEAR` |
| **掉电保存** | 阈值参数写入 Flash，带校验位 + 字节对齐 |
| **门锁控制** |支持上位机远程锁门/解锁，锁门后本地按键失效 |
| **安防计数** |锁门期间检测到人，计数 +1 并上报，解锁时汇总 |

## 状态机设计

系统采用 **6 状态非阻塞状态机** 管理整个交互流程：

### 状态1：数据面板（主界面）
- 显示：温度、湿度、光照、土壤、PWM占空比、系统状态
- 后台：传感器采集、自动控制、报警判断
- KEY1 短按 → 进入状态2
- 二级异常 ≥3 → 自动进入状态4

### 状态2：选择指标
- 显示：Temp / Humi / Light / Soil（带光标）
- KEY1 短按 → 切换指标
- KEY1 长按 → 进入状态3
- KEY2 短按 → 返回状态1

### 状态3：调节阈值
- 显示：当前指标的最大/最小阈值（带光标）
- 编码器旋转 → 调节数值
- KEY1 短按 → 切换最大值/最小值
- KEY1 长按 → 保存到 Flash，显示 "Saved!"，返回状态1
- KEY2 短按 → 返回状态2

### 状态4：系统报警
- 显示：`!! SYSTEM ALERT !!` + 异常指标列表
- 蜂鸣器持续响，屏幕闪烁
- KEY2 长按 → 退出状态4，锁定（不再自动进入）
- 触发条件：二级异常 ≥3

### 报警锁定与解锁
- **锁定后**：即使二级异常 ≥3，也不再自动进入状态4
- **解锁条件**（三种）：
  ① 状态1 长按 KEY2
  ② 上位机 `ALARM CLEAR` 指令
  ③ 异常全部恢复（自动解锁）

### 状态5：安防警报
- 门锁定状态下，红外检测到人 → 屏幕显示 "!! SECURITY !!" + 蜂鸣器
- 不开门，计数 +1，串口上报
- 只有上位机 DOOR UNLOCK 才能解除

### 状态6：开门联动
- 红外检测到人 → 舵机开门
- 人离开后 3 秒 → 舵机关门
- 通过“最后检测时间”实现人走延时关门

### 按键功能一览

| 状态 | KEY1 短按 | KEY1 长按 | KEY2 短按 | KEY2 长按 | 编码器 |
|------|-----------|-----------|-----------|-----------|--------|
| 状态1 | 进入状态2 | - | - | 解锁报警 | - |
| 状态2 | 切换指标 | 进入状态3 | 返回状态1 | - | - |
| 状态3 | 切换最大/最小 | 保存并返回状态1 | 返回状态2 | - | 调节数值 |
| 状态4 | - | - | - | 退出+锁定 | - |

## 📖 使用指南

### 1. 上电启动
上电后系统自动进入开机动画（1.5s），随后进入数据面板。

### 2. OLED 界面说明

| 状态 | 界面内容 |
|------|----------|
| 数据面板 | 温度、湿度、光照、土壤、PWM 占空比、系统状态 |
| 选择指标 | 4 个指标名 + 光标 |
| 调节阈值 | 当前指标的最大/最小值 + 光标 |
| 系统报警 | `!! SYSTEM ALERT!` + 异常指标列表 |
| 安防报警 | `!! SECURITY !!` + `Person Detected!` |
| 开门联动 | `Door Open!` + 实时数据 |

### 3. 串口指令

| 指令 | 功能 |
|------|------|
| `GET` | 查询当前数据 |
| `SET T 20 35` | 设置温度阈值 |
| `SET H 40 80` | 设置湿度阈值 |
| `SET L 1500 3000` | 设置光照阈值 |
| `SET S 30 70` | 设置土壤阈值 |
| `CTRL FAN ON/OFF` | 手动控制风扇 |
| `CTRL HUM ON/OFF` | 手动控制雾化器 |
| `CTRL PUMP ON/OFF` | 手动控制水泵 |
| `MODE AUTO/MANUAL` | 切换自动/手动模式 |
| `DOOR OPEN/CLOSE` | 开门/关门 |
| `DOOR LOCK/UNLOCK` | 锁门/解锁（锁门后本地按键失效） |
| `ALARM CLEAR` | 解除系统报警锁定 |

### 4. 锁门与安防计数

- **锁门**：发 `DOOR LOCK`，门锁定，本地按键失效
- **锁门期间检测到人**：不开门，计数 +1，串口上报
- **解锁**：发 `DOOR UNLOCK`，上报总人数，计数清零

### 5. 上电预热

HC-SR505 红外模块上电后需要 20 秒预热，期间不响应红外触发。

## 核心设计

- **非阻塞状态机**：按键、编码器、显示、控制全部基于时间戳，主循环无 `delay`
- **三级报警机制**：良好 / 一级异常 / 二级异常，工业级“报警确认/复位”分离设计
- **Flash 掉电保存**：校验位放首位、4 字节对齐、定点数存储
- **电源分离 + 单点共地**：逻辑电源和功率电源分离，抑制感性负载干扰
- **串口协议**：超时判断帧结束，不依赖换行符，兼容不定长指令
- **任务解耦**：IR_Task / Buzzer_Task / OLED_Task 独立于状态机，实现“准并行”，状态切换时传感器采集和显示不受影响
