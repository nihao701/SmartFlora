# SmartFlora

#### 介绍
基于 STM32F103C8T6 的智能花房控制系统，集成环境监测、自动控制、多级报警、安防联动与上位机通信。系统采用非阻塞状态机架构，实现传感器采集、OLED 交互、阈值调节、执行器联动的完整闭环，并通过 Flash 实现阈值掉电保存。
技术栈： STM32F103 | 标准库 | 状态机 | ADC | I2C | UART | PWM | 外部中断 | Flash 模拟 EEPROM
